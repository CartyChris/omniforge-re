# OmniForge RE — feature traceability

Every section of the original specification, with an honest status. **"Verified" means a check that can fail was run and passed**; the evidence is named. Nothing here is a mock-up: where a capability depends on something this build environment could not provide (a Mac, API keys, your accounts), it says so.

Statuses: **V** Implemented and Verified · **U** Implemented but Unverified · **P** Partially Implemented · **N** Not Implemented · **X** Unsupported (deliberately; see reason).

Evidence key: *unit* = vitest (core 242, server 97) · *e2e* = Playwright on the production build (44 tests on GitHub Actions; desktop + mobile projects), run locally and in CI · *real-X* = ran against the real tool, not a stand-in · *mutation* = the guard was disabled and the test confirmed to fail.

## Supply chain and licences (added after the integration research)

- **Repo Rip licence gate — fixed.** Running the old detector on real licence texts showed it classified Convex's source-available FSL-1.1 as permissive Apache-2.0 (no attestation required), read MPL-2.0 and Directus's MSCL as GPL-3.0 and returned UNKNOWN for line-wrapped ISC. Licences are now identified by their own heading, whitespace-normalised, and a new `source-available` class (FSL, MSCL, Sustainable Use, Elastic-2.0, BUSL, SSPL, PolyForm, Commons Clause, CC-BY-NC) always requires the user's attestation. **V:** 19 tests against real licence texts (fixtures in `packages/core/test/fixtures/licenses`), two mutation checks.
- **Nodebox removed from the shipped preview.** `@codesandbox/nodebox` (a transitive dependency of Sandpack) is under the Sustainable Use License (internal-business / non-commercial use only), and the old preview selected the `vite-react-ts` template, which runs on it — the production bundle contained its runtime URL. The preview now uses bundler templates only and the package is replaced by a stub at build time. **V:** `scripts/check-bundle.mjs` failed on the old bundle and passes on the new one; CI runs it after every build together with `scripts/license-audit.mjs` (all 180 production packages must be under an allowed licence; the only exception is Nodebox, valid only while its marker is absent from the bundle — mutation-checked).
- **Decisions that still need you** (details in `docs/integration-research.md`): WebContainers (not adopted), bundling `axe-core` (MPL-2.0) if the compare engine adds it, Wappalyzer-format rule import, bundling Java tools, browser MCP servers, hosted-rendering spikes.
